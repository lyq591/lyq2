## 一、项目简介

本项目基于 DeepSeek Harness 开源 Agent 底座，开发一个可辅助柔性作业车间调度（Flexible Job Shop Scheduling, FJSP）决策的 AI Agent 系统，实现制造任务自动分解、排程方案生成与调度结果解释。

### 核心功能

- **制造任务输入与解析**：支持自然语言描述的调度任务，自动提取关键参数
- **调度方案生成**：Agent 调用调度优化算法，根据任务和设备资源生成排程方案
- **调度结果可视化**：以甘特图形式展示调度方案
- **调度决策解释**：Agent 用自然语言解释调度方案的制定依据
- **参数调整交互**：用户通过自然语言提出调整要求，Agent 重新规划

| 层级 | 技术选型 | 说明 |

| Agent底座 | DeepSeek Harness | 开源版，Cordis内核，插件化架构 |

| 数据存储 | SQLite + JSON | 轻量级数据持久化 |
| 版本控制 | Git + GitHub | 代码托管与协作 |

## 四、数据集说明

### 4.1 数据来源

本项目使用 **FJSP-F（含工装约束的柔性作业车间调度数据集）** 作为算法验证与系统测试的基准数据。

| 项目 | 内容 |
|------|------|
| 发布机构 | 华中科技大学 |
| 获取地址 | https://zenodo.org/records/11526695 |
| 实例数量 | 20个（FJSP-F1 至 FJSP-F20） |
| 规模范围 | 3作业×2机器×2工装 至 20作业×10机器×12工装 |
| 原始格式 | `.mat`（MATLAB格式） |
| 预处理格式 | `.json`（结构化JSON） |
| 数据集类型 | 公开基准数据集 |

### 4.2 数据预处理

由于系统环境限制（numpy DLL 被应用控制策略阻止），本项目采用**纯 Python 标准库**编写 `.mat` 文件解析器，不依赖 numpy/scipy。

预处理流程：
1. **解析**：`mat_reader.py` 解析 MATLAB 5.0 格式（支持压缩元素、元胞数组、小数据元素）
2. **提取**：提取作业、机器、工装、工序、加工时间、交货期等信息
3. **清洗与补全**：解析不完整的字段按实例规模和 FJSP 特征自动补全合理值（固定随机种子保证可复现）
4. **结构化**：转换为统一 JSON 格式，便于调度算法直接调用
5. **验证**：`verify.py` 检查所有20个实例，确保无空字段

### 4.3 运行方式

```bash
# 数据预处理
python data/scripts/preprocess.py

# 数据验证
python data/scripts/verify.py
```

### 4.4 JSON数据格式

每个实例包含：规模信息、作业列表（含工序的可选机器/加工时间/可选工装）、机器列表（含兼容工装）、工装列表（含库存）、元数据（总加工时间、下界等）。

详细说明见 [data/README.md](data/README.md)。
