## 一、项目简介

本项目基于 DeepSeek Harness 开源 Agent 底座思想，开发一个可辅助柔性作业车间调度（Flexible Job Shop Scheduling, FJSP）决策的智能系统，实现制造任务自动解析、排程方案生成、调度结果可视化与决策解释。

### 核心功能

- **制造任务输入与解析**：支持标准FJSP实例加载与自定义任务
- **智能调度求解**：遗传算法（GA）求解FJSP调度问题，POX交叉、锦标赛选择
- **调度结果可视化**：ECharts甘特图展示调度方案
- **工业数据分析**：数据集统计分析、瓶颈识别、负载均衡分析
- **调度决策解释**：自然语言解释调度决策依据（关键路径、设备分配理由）
- **数字孪生车间**：实时映射车间设备运行状态，展示调度执行过程
- **完整B/S架构**：Flask后端 + Vue3前端 + SQLite数据库

## 四、快速开始

### 4.1 环境要求

- Python 3.8+
- 现代浏览器（Chrome/Edge/Firefox）

### 4.2 安装依赖

```bash
cd backend
pip install -r requirements.txt
```

### 4.3 一键启动（推荐）

**方式一：双击启动（最简单）**

直接双击项目根目录下的 `启动系统.bat`，自动启动前后端并打开浏览器。

**关闭系统**：双击 `关闭系统.bat`，自动停止所有服务并释放端口。

**方式二：命令行启动**

```bash
python start.py
```

该程序会自动：
1. 检查 Python 环境与后端依赖
2. 检查端口是否被占用
3. 启动后端服务（http://127.0.0.1:8000）
4. 启动前端服务（http://127.0.0.1:5500）
5. 自动打开浏览器
6. 实时显示前后端日志
7. 按 Ctrl+C 优雅停止所有服务

### 4.4 手动启动

**启动后端：**
```bash
cd backend
python main.py
```
后端API地址：http://127.0.0.1:8000

**启动前端（另开终端）：**
```bash
cd frontend
python -m http.server 5500
```
前端地址：http://127.0.0.1:5500

### 4.5 运行测试

```bash
python tests\run_tests.py
```
或双击 `scripts\run_tests.bat`

## 七、算法说明

### 7.1 遗传算法（GA）求解FJSP

**染色体编码**：两段式编码
- 操作序列：每个作业号出现其工序数次，表示工序加工优先级
- 机器分配：每个操作选择一台可选机器

**遗传操作**：
- **选择**：锦标赛选择（k=3）
- **交叉**：POX（Precedence Operation Crossover）交叉操作序列，均匀交叉机器分配
- **变异**：操作序列交换变异、机器分配随机重选
- **精英保留**：每代保留最优个体

**解码**：按操作序列顺序调度，每道工序的开始时间 = max(机器可用时间, 作业上道工序完成时间, 工装可用时间)

**适应度**：1 / Makespan（总工期越小，适应度越高）

### 7.2 调度决策解释

系统自动分析调度结果并生成自然语言解释，包括：
- 关键路径作业识别
- 机器负载均衡分析
- 高/低负荷机器识别
- 交货期满足情况分析
- 调度优化建议
