## 1. 引言

### 1.1 编写目的

本文档旨在明确"柔性作业车间智能调度辅助Agent系统"的功能需求与非功能需求，为系统设计、开发、测试和验收提供依据。本文档的读者包括项目开发人员、指导教师、课程评审人员及最终用户。

### 1.2 项目背景

柔性作业车间调度问题（Flexible Job Shop Scheduling Problem, FJSP）是经典作业车间调度问题的扩展，每道工序可在多台可选机器上加工，求解复杂度显著增加。在实际制造场景中，还需考虑工装约束、交货期、优先级等多种因素。

本项目借鉴 DeepSeek Harness 开源 Agent 底座的设计思想，开发一个面向柔性作业车间的智能调度辅助系统，通过遗传算法自动生成调度方案，并提供可视化展示与决策解释，辅助车间管理人员进行排程决策。

### 1.3 术语定义

| 术语 | 定义 |
|------|------|
| FJSP | 柔性作业车间调度问题（Flexible Job Shop Scheduling Problem） |
| Makespan | 总工期，即所有作业完成的最大时间 |
| GA | 遗传算法（Genetic Algorithm） |
| POX | 保序交叉（Precedence Operation Crossover） |
| 工装 | 加工过程中使用的夹具、刀具等工艺装备 |
| 瓶颈机器 | 可选工序数最多、负荷最高的机器 |
| 关键路径 | 决定总工期的作业加工路径 |

## 2. 总体描述

### 2.1 产品视角

本系统为 B/S 架构的 Web 应用，后端采用 Python Flask 提供 RESTful API，前端采用 Vue 3 + ECharts 构建单页应用，数据存储使用 SQLite 轻量级数据库。系统无需复杂部署，可在普通个人电脑上运行。

### 2.2 用户特征

| 用户角色 | 描述 | 技术水平 |
|----------|------|----------|
| 车间调度员 | 主要使用者，负责制定车间排程方案 | 中等，能操作Web界面 |
| 车间管理人员 | 查看调度结果与分析报告 | 基础，能浏览网页 |
| 系统管理员 | 维护系统运行与数据 | 较高，了解Python与Web技术 |

### 2.3 运行环境

- **操作系统**：Windows 10/11（兼容 Linux/macOS）
- **Python**：3.8 及以上版本
- **浏览器**：Chrome 90+ / Edge 90+ / Firefox 88+
- **内存**：最低 2GB，推荐 4GB 以上
- **网络**：首次加载前端需访问 CDN（Vue3、ECharts），后续可离线使用

### 2.4 设计约束

1. **纯Python实现约束**：因系统应用控制策略限制，numpy、pandas、pydantic 等含原生DLL的库无法使用，后端算法与数据处理必须采用纯Python实现。
2. **Web框架约束**：后端采用 Flask（纯Python），不使用 FastAPI（依赖pydantic原生库）。
3. **前端约束**：采用 CDN 引入 Vue 3 和 ECharts，无需 Node.js 构建环境。
4. **数据库约束**：使用 SQLite，无需额外安装数据库服务。

### 2.5 假设与依赖

1. 假设用户已安装 Python 3.8+ 环境。
2. 假设输入的 FJSP 实例数据格式符合系统定义的 JSON 格式。
3. 假设遗传算法的求解质量在可接受范围内（课程设计场景，不追求工业级最优解）。
4. 依赖 FJSP-F 公开数据集作为测试与演示数据。

## 3. 功能需求

### 3.1 系统功能概览

| 编号 | 功能模块 | 功能描述 | 优先级 |
|------|----------|----------|--------|
| F1 | 数据集管理 | 加载、浏览、统计 FJSP 实例数据 | 高 |
| F2 | 智能调度求解 | 基于遗传算法的 FJSP 调度求解 | 高 |
| F3 | 调度结果可视化 | 甘特图、收敛曲线、机器利用率展示 | 高 |
| F4 | 工业数据分析 | 实例统计、瓶颈识别、多实例对比 | 中 |
| F5 | 调度决策解释 | 自然语言解释调度方案与优化建议 | 中 |
| F6 | 数字孪生车间 | 车间设备运行状态实时映射与动画 | 中 |
| F7 | 调度历史管理 | 调度任务记录、结果查询与追溯 | 中 |
| F8 | 系统日志 | 记录系统运行状态与操作日志 | 低 |

### 3.2 数据集管理（F1）

#### 3.2.1 实例列表浏览

- **需求编号**：F1.1
- **描述**：系统应展示所有已加载的 FJSP 实例列表，包括实例ID、作业数、机器数、工装数、总加工时间等基本信息。
- **输入**：无（系统自动加载 data/processed 目录下的 JSON 文件）
- **输出**：实例列表表格，支持按规模排序
- **验收标准**：正确显示全部20个FJSP-F实例，信息准确无误

#### 3.2.2 实例详情查看

- **需求编号**：F1.2
- **描述**：用户可查看单个实例的详细信息，包括规模参数、每个作业的工序详情、可选机器与加工时间、工装约束、交货期与优先级。
- **输入**：实例ID（如 FJSP-F1）
- **输出**：实例详情弹窗/页面，展示完整数据
- **验收标准**：详情数据与JSON源文件一致，工序信息完整

#### 3.2.3 实例统计分析

- **需求编号**：F1.3
- **描述**：系统应提供实例的统计信息，包括总工序数、平均工序数、加工时间统计（均值/最小/最大/标准差）、机器负荷分布、工装使用分布、交货期统计、优先级分布。
- **输入**：实例ID
- **输出**：统计信息字典 + 机器负荷柱状图
- **验收标准**：统计数据可复现，与手动计算一致

### 3.3 智能调度求解（F2）

#### 3.3.1 参数配置

- **需求编号**：F2.1
- **描述**：用户可配置遗传算法参数，包括种群大小（默认100）、最大迭代代数（默认200）、随机种子（默认42）。
- **输入**：实例ID + 算法参数
- **输出**：无（参数传递给求解器）
- **约束**：种群大小范围 10-500，迭代代数范围 10-1000
- **验收标准**：参数校验有效，非法参数给出提示

#### 3.3.2 调度求解执行

- **需求编号**：F2.2
- **描述**：系统基于遗传算法求解 FJSP 调度问题，考虑机器可选性、工装约束、工序优先级约束。算法采用 POX 交叉、锦标赛选择、精英保留策略。
- **输入**：实例数据 + 算法参数
- **输出**：调度结果（Makespan、机器调度表、作业调度表、机器利用率、收敛历史）
- **性能要求**：FJSP-F1（3作业×2机器）求解时间 < 1秒；FJSP-F20（20作业×10机器）求解时间 < 30秒
- **验收标准**：调度结果合法（无工序冲突、满足工艺约束），Makespan > 0

#### 3.3.3 自定义任务调度

- **需求编号**：F2.3
- **描述**：支持用户输入自定义的 FJSP 任务数据（作业、工序、可选机器、加工时间），无需预存实例即可进行调度求解。
- **输入**：自定义任务JSON
- **输出**：调度结果
- **验收标准**：能正确解析自定义数据并求解

### 3.4 调度结果可视化（F3）

#### 3.4.1 甘特图展示

- **需求编号**：F3.1
- **描述**：以甘特图形式展示调度方案，横轴为时间，纵轴为机器，每个色块表示一道工序的加工时段，颜色区分不同作业，鼠标悬停显示工序详情。
- **输入**：调度结果中的机器调度表
- **输出**：ECharts 甘特图
- **验收标准**：工序位置与时间准确，颜色区分清晰，交互正常

#### 3.4.2 收敛曲线展示

- **需求编号**：F3.2
- **描述**：展示遗传算法的收敛过程，包括每代最优 Makespan 和平均 Makespan 的变化曲线。
- **输入**：收敛历史数据
- **输出**：ECharts 折线图（双曲线）
- **验收标准**：曲线数据与收敛历史一致，最优值单调不增

#### 3.4.3 机器利用率展示

- **需求编号**：F3.3
- **描述**：以卡片形式展示每台机器的利用率（加工时间/总工期×100%），高利用率机器标红提示。
- **输入**：机器利用率数据
- **输出**：利用率卡片组
- **验收标准**：利用率计算准确，范围0-100%

### 3.5 工业数据分析（F4）

#### 3.5.1 瓶颈识别

- **需求编号**：F4.1
- **描述**：分析实例数据，识别潜在瓶颈机器（可选工序数超过平均负荷120%的机器）和瓶颈工装，给出优化建议。
- **输入**：实例ID
- **输出**：瓶颈机器列表 + 瓶颈工装列表 + 建议文本
- **验收标准**：瓶颈识别逻辑正确，建议合理

#### 3.5.2 多实例对比

- **需求编号**：F4.2
- **描述**：支持选择多个实例进行横向对比，对比维度包括作业数、机器数、工装数、总工序数、平均加工时间、总加工时间。
- **输入**：实例ID列表
- **输出**：对比表格
- **验收标准**：对比数据准确，支持任意实例组合

#### 3.5.3 数据集概览

- **需求编号**：F4.3
- **描述**：提供整个数据集的概览信息，包括实例总数、规模范围（作业/机器/工装的最小最大值）、跨实例总作业数、总工序数、平均/最大总加工时间。
- **输入**：无
- **输出**：概览统计 + 实例规模分布图
- **验收标准**：概览数据与全部实例汇总一致

### 3.6 调度决策解释（F5）

#### 3.6.1 自然语言解释

- **需求编号**：F5.1
- **描述**：系统自动分析调度结果，生成自然语言解释，包括：总工期说明、关键路径作业识别、机器负载均衡分析、高/低负荷机器提示、交货期满足情况分析、优化建议。
- **输入**：调度结果 + 实例数据
- **输出**：自然语言解释文本（不少于100字）
- **验收标准**：解释内容与调度数据一致，逻辑通顺，包含关键要素

### 3.7 数字孪生车间（F6）

#### 3.7.1 车间状态映射

- **需求编号**：F6.1
- **描述**：基于调度结果，以动画形式展示车间设备的运行状态。每台机器显示当前加工的作业、加工进度；每个作业显示等待/加工/完成状态。支持播放/暂停控制。
- **输入**：实例ID + 调度结果
- **输出**：数字孪生车间动画界面
- **验收标准**：机器状态与调度时间线一致，动画流畅，控制正常

### 3.8 调度历史管理（F7）

#### 3.8.1 历史记录查询

- **需求编号**：F7.1
- **描述**：记录每次调度任务的参数、状态、结果，支持按时间倒序浏览历史记录，可查看单次调度的完整结果。
- **输入**：查询参数（limit、实例筛选）
- **输出**：历史记录列表 + 详情
- **验收标准**：记录完整，可追溯，与数据库一致

### 3.9 系统日志（F8）

#### 3.9.1 日志记录与查询

- **需求编号**：F8.1
- **描述**：记录系统运行日志（信息/警告/错误三级），支持按级别筛选查询。
- **输入**：日志级别筛选
- **输出**：日志列表
- **验收标准**：关键操作均有日志记录

## 5. 接口需求

### 5.1 后端API接口

系统采用 RESTful API 设计，基础路径为 `http://127.0.0.1:8000/api`，数据格式为 JSON。

#### 5.1.1 系统接口

| 方法 | 路径 | 描述 |
|------|------|------|
| GET | `/` | 系统信息 |
| GET | `/api/health` | 健康检查（含数据库统计） |

#### 5.1.2 数据集接口

| 方法 | 路径 | 描述 |
|------|------|------|
| GET | `/api/dataset/instances` | 获取实例列表 |
| GET | `/api/dataset/{instance_id}` | 获取实例详情 |
| GET | `/api/dataset/{instance_id}/stats` | 获取实例统计 |
| GET | `/api/dataset/{instance_id}/bottlenecks` | 识别瓶颈 |
| GET | `/api/dataset/overview` | 数据集概览 |

#### 5.1.3 调度接口

| 方法 | 路径 | 描述 |
|------|------|------|
| POST | `/api/schedule` | 执行调度求解 |
| POST | `/api/schedule/custom` | 自定义任务调度 |
| GET | `/api/schedule/results` | 调度历史列表 |
| GET | `/api/schedule/results/{id}` | 调度结果详情 |
| GET | `/api/schedule/latest/{instance_id}` | 最新调度结果 |

**调度请求体示例：**
```json
{
  "instance_id": "FJSP-F1",
  "pop_size": 100,
  "max_gen": 200,
  "seed": 42
}
```

#### 5.1.4 分析接口

| 方法 | 路径 | 描述 |
|------|------|------|
| GET | `/api/analysis/compare?instances=F1,F10` | 多实例对比 |
| GET | `/api/analysis/schedule/{instance_id}` | 调度结果分析 |

#### 5.1.5 日志接口

| 方法 | 路径 | 描述 |
|------|------|------|
| GET | `/api/logs?limit=50&level=error` | 系统日志查询 |

### 5.2 前端-后端交互

- 前端通过 `fetch` API 调用后端接口
- 所有请求为异步调用，避免阻塞UI
- 调度接口为耗时操作，前端显示加载状态
- API不可用时，前端显示连接状态提示

### 5.3 数据接口

- 实例数据：JSON格式，存储于 `data/processed/` 目录
- 数据库：SQLite，文件存储于 `backend/fjsp_scheduler.db`
- 原始数据：MATLAB .mat 格式，存储于 `data/raw/` 目录

### 6.2 数据库表结构

#### 6.2.1 调度任务表（schedule_tasks）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER | 主键，自增 |
| instance_id | TEXT | 实例ID |
| instance_name | TEXT | 实例名称 |
| parameters | TEXT | 算法参数（JSON） |
| status | TEXT | 状态（pending/running/completed/failed） |
| result | TEXT | 结果摘要（JSON） |
| makespan | REAL | 总工期 |
| elapsed_time | REAL | 求解耗时（秒） |
| created_at | REAL | 创建时间戳 |
| updated_at | REAL | 更新时间戳 |

#### 6.2.2 调度结果表（schedule_results）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER | 主键，自增 |
| task_id | INTEGER | 关联任务ID |
| instance_id | TEXT | 实例ID |
| makespan | REAL | 总工期 |
| machine_schedule | TEXT | 机器调度表（JSON） |
| job_schedule | TEXT | 作业调度表（JSON） |
| machine_utilization | TEXT | 机器利用率（JSON） |
| convergence_history | TEXT | 收敛历史（JSON） |
